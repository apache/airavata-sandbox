This benchmark measures cache behavior under file modification scenarios.
Staleness rate = probability a file is modified between consecutive reads.

Key Insights:
--------------------------------------------------------------------------------
- At 50% staleness: RemoteFS consistency = 100.0%, SSHFS default = 56.8%
  -> RemoteFS maintains data consistency while SSHFS default returns stale data
- At 0% staleness: RemoteFS cached (641.56 MB/s) >= Direct (121.85 MB/s)
  -> Cache provides performance benefit for stable files

Recommendations:
- Use RemoteFS for data consistency (bounded staleness ~1s in production)
- SSHFS default is faster but may return stale data indefinitely
- SSHFS nocache is consistent but has high per-read latency
