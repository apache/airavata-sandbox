Key Insights:
--------------------------------------------------------------------------------
- At 50% staleness: RemoteFS consistency = 100.0%, SSHFS default = 56.8%
  -> RemoteFS maintains data consistency while SSHFS default returns stale data
- At 0% staleness: RemoteFS cached (726.62 MB/s) >= Direct (154.07 MB/s)
  -> Cache provides performance benefit for stable files

Recommendations:
- Use RemoteFS for data consistency (always 100% correct)
- SSHFS default is faster but may return stale data
- SSHFS nocache is consistent but has high latency
